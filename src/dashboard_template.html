How it would run in production

  1. Collect

    Requests arrive by WhatsApp, email, web form or the client's own system and land in one queue.

  2. Understand

    An LLM turns free text into a structured request (parcels, time window, priority, address) checked against a strict schema. Unclear messages go to a person.

  3. Plan

    OR-Tools solves the routing problem with time windows, van capacity and priorities, using road travel times.

  4. Dispatch

    Each driver gets an ordered stop list with ETAs on their phone.

  5. Re-plan

    New requests, cancellations or delays trigger a fresh solve in seconds. Stops already under way stay locked.

  6. Report

    Dashboard and daily report: parcels per driver-hour, missed pickups and why, distance driven.
